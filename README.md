# 2x2 Rubik's Cube Solver
---
This project is a JavaScript implementation of an optimal move 2x2 Rubik's Cube solver. It includes a live webpage that allows the user to interact with the cube, edit the facelets and find the optimal solution to the input cube.

---

## Live Demo
[https://compro72.github.io/2x2-Rubik-s-Cube-Solver/](https://compro72.github.io/2x2-Rubik-s-Cube-Solver/)

## Features
- A 2D and 3D interactive 2x2 cube built with CSS transforms
- A cube scrambler for testing the solver
- A bi-directional breath first search implementation for finding the optimal solution
- Pre-computed search tree for the first 7 moves from the solved state
